Bab 1: Wewenang Pajak: Ketua Peneliti Sebagai Pemotong WPOP

Dalam tata kelola dana hibah penelitian kompetitif perguruan tinggi (Kemendikbudristek / DRTPM BIMA), kontrak penelitian menetapkan bahwa Ketua Peneliti (Dr. Siti Rahayu Nadhiroh, S.KM., M.Kes.) adalah penerima hibah dan penanggung jawab mutlak atas aspek akademik, tata kelola keuangan, serta seluruh kewajiban perpajakan yang timbul.

💡 Mengapa yang Menginput Pajak adalah Ketua Peneliti Langsung?

Sesuai regulasi PMK 168/2023 & UU Harmonisasi Peraturan Perpajakan (HPP), Ketua Peneliti bertindak sebagai Wajib Pajak Orang Pribadi (WPOP) Pemotong Pajak yang mempekerjakan narasumber, pengolah data, dan tim enumerator lapangan.
Oleh karena itu, penerbitan Bukti Potong PPh 21 (Formulir 1721-VIII) dilakukan langsung dari akun DJP Online pribadi milik Ketua Peneliti (menggunakan NIK 16 digit / NPWP pribadi Bu Nadhiroh), bukan oleh LPPM ataupun bendahara universitas.

🔑 Cara Aktivasi Fitur e-Bupot 21/26 di Akun DJP Bu Nadhiroh:

  1. Login ke djponline.pajak.go.id dengan NIK 16 digit KTP / NPWP & kata sandi DJP Bu Nadhiroh.
  2. Buka tab Profil → pilih sub-menu Aktivasi Fitur Layanan.
  3. Centang opsi e-Bupot 21/26 → klik tombol Ubah Fitur Layanan → konfirmasi Ya.
  4. Sistem DJP otomatis logout. Setelah login ulang, menu e-Bupot 21/26 sudah siap dipakai di tab Layanan / Lapor.

Bab 2: Mengapa Coretax Meminta Format XML & Alur Impor BP21

💡 Mengapa Saat Klik "Impor Data", Coretax DJP Meminta File Format XML (*.xml)?

Dalam pembaruan sistem Coretax DJP (PSIAP), Direktorat Jenderal Pajak resmi menghapus impor CSV lama dan mewajibkan standar XML (*Extensible Markup Language*).
Khusus untuk honorarium narasumber, pengolah data, dan petugas survei (selain pegawai tetap), jenis dokumennya dinamakan BP21 (Bukti Pemotongan PPh 21 Selain Pegawai Tetap). Itulah sebabnya saat tombol "Impor data" ditekan di layar Coretax, Windows Explorer otomatis memfilter: XML File (*.xml).

A
Metode 1: Ekspor XML BP21 dari ZanFin (Rekomendasi Cepat — Langsung Upload!)

ZanFin sudah dilengkapi Generator XML Coretax BP21 Resmi. Cukup buka menu Pajak & Coretax di ZanFin → klik tombol "⚡ Ekspor XML Coretax BP21". File BP21_Coretax_DJP_*.xml langsung terunduh.
Buka layar Coretax akun Bu Nadhiroh → klik dropdown Impor data → pilih file XML tersebut → klik Open. Ke-14 Bukti Potong terbit otomatis dalam 3 detik!

B
Metode 2: Menggunakan File Converter Resmi DJP (BP21 Excel to XML v.4.xlsx)

Bila menggunakan converter resmi dari DJP: unduh file BP21 Excel to XML v.4.xlsx dari laman pajak.go.id, salin data 14 orang dari tabel Bab 4 ke sheet DATA, aktifkan tab Developer di Microsoft Excel, klik tombol Export untuk menghasilkan file .xml, lalu unggah ke Coretax.

C
Metode 3: Perekaman Manual di Web Coretax (Tombol "+ Create eBupot BP21")

Bila ingin input satu per satu secara manual melalui form web: klik tombol + Create eBupot BP21 pada layar Coretax, masukkan NIK 16 digit penerima, pilih Kode Objek Pajak (KOP), input DPP bruto & nomor kuitansi, lalu simpan.

Langkah Demi Langkah Perekaman Formulir Manual BP21 di Coretax:

1
Login ke DJP Akun Ketua Peneliti & Buka e-Bupot BP21 Akses djponline.pajak.go.id dengan NIK/NPWP Bu Nadhiroh. Masuk ke tab e-Bupot 21/26 → pilih Daftar Bukti Potong 21/26 → klik tombol + Create eBupot BP21.
2
Identitas Wajib Pajak Penerima Penghasilan Pilih opsi identitas NIK (16 Digit Sesuai KTP) atau NPWP. Masukkan nomor NIK yang tertera di ZanFin. Klik tombol Cek NIK; sistem Coretax DJP akan otomatis memverifikasi nama penerima langsung dari server Dukcapil Kemendagri.
3
Pemilihan Kode Objek Pajak (KOP Resmi Coretax BP21) Pilih kode objek pajak baku Coretax sesuai tugas personel:
  • 21-100-18 (Imbalan kepada Penasihat, Pengajar, Penceramah, Moderator): Untuk 5 Narasumber FGD & Diseminasi.
  • 21-100-20 (Imbalan kepada Pemberi Jasa dalam Segala Bidang): Untuk 1 Pengolah Data Gizi & Tabulasi.
  • 21-100-24 (Upah Pegawai Tidak Tetap Harian/Satuan/Borongan ≤ Rp2.500.000): Untuk 8 Petugas Survei Lapangan (Enumerator RT).

Nomor DokumenDiisi Nomor Referensi ZanFin (misal: KWT-HR-056-1, KWT-HR-017, dst.)
Tanggal DokumenDiisi Tanggal Kuitansi ZanFin (misal: 30/08/2026 atau 21/08/2026)

⚠️ Pertanyaan Kritis: "Bagaimana dengan Upload Bukti Bayar (Kwitansi) di e-Bupot?"

Fakta Teknis DJP Online: Sistem e-Bupot 21/26 TIDAK meminta pengguna meng-upload file scan foto/PDF kuitansi ke server DJP saat menerbitkan bukti potong. Yang diwajibkan oleh DJP hanyalah mencatat Nomor Dokumen & Tanggal Dokumen sebagai referensi hukum.

Lalu kemana bukti kuitansi & slip gaji harus di-upload / disimpan?
File foto transfer m-banking, slip gaji bertanda tangan basah, dan kuitansi bermaterai adalah berkas wajib Laporan Pertanggungjawaban (SPJ/LPJ Hibah Riset) untuk universitas (LPPM UNAIR) dan Kemendikbudristek (Sistem BIMA). Di ZanFin, fitur Unggah Bukti Transfer / Nota sudah tersedia di setiap slip honor sehingga Anda memiliki arsip digital yang rapi dan siap cetak sewaktu diperiksa auditor BPK / Inspektorat.

Alur Integrasi ZanFin ke e-Bupot Akun Ketua & SPJ Universitas:

1. Buat & Validasi Slip di ZanFin: Setiap honor dibuatkan kuitansi dan dilampirkan struk transfer / nota.
2. Ekspor File Coretax CSV: Klik satu tombol di menu Pajak & Coretax untuk mengunduh tabel siap impor.
3. Terbitkan Bukti Potong 1721-VIII: Di e-Bupot DJP Online akun Ketua Peneliti, cetak formulir Bukti Potong PPh 21 resmi (ber-barcode DJP).
4. Satukan Berkas SPJ: Pasangkan Bukti Potong DJP + Kuitansi ZanFin + Struk Transfer Bank → Satukan ke Bundel SPJ Riset BIMA / LPPM UNAIR.

Bab 5: Checklist Kelengkapan Dokumen SPJ Audit Riset

Sesuai regulasi Peraturan Menteri Keuangan (PMK) dan Panduan Pelaksanaan Hibah Riset Kemendikbudristek, setiap pengeluaran honorarium wajib memiliki berkas pendukung fisik / digital lengkap. Gunakan checklist berikut saat menyusun LPJ:

Berkas Pendukung Honorarium Narasumber (FGD, Workshop, Diseminasi):

  • ☑ Surat Undangan Resmi sebagai narasumber dari Ketua Peneliti.
  • ☑ Surat Kesediaan bertanda tangan dari narasumber.
  • ☑ Curriculum Vitae (CV) / Portofolio Keahlian narasumber.
  • ☑ Materi / Bahan Tayang Paparan (Slide presentasi PPT/PDF).
  • ☑ Daftar Hadir Narasumber & Peserta Acara bertanda tangan.
  • ☑ Dokumentasi Foto Kegiatan dengan timestamp lokasi (GPS/Waktu).
  • ☑ Kuitansi Pembayaran Honorarium resmi (sesuai nomor ZanFin).
  • ☑ Bukti Transfer Bank (struk mutasi m-banking / bukti setor).
  • ☑ Bukti Potong PPh 21 (Form 1721-VIII) terbitan resmi dari e-Bupot DJP.

Berkas Pendukung Petugas Survei Lapangan (8 Enumerator RT):

  • ☑ Surat Keputusan (SK) / Surat Tugas Tim Enumerator Lapangan dari Dekan/LPPM.
  • ☑ Fotokopi KTP (NIK 16 Digit) & Kartu NPWP masing-masing enumerator.
  • ☑ Logbook / Berita Acara Rekapitulasi kuota responden (160 RT terpenuhi).
  • ☑ Kuitansi Tanda Terima Honor bertanda tangan masing-masing penerima (Rp 1.216.000 netto).
  • ☑ Bukti Transfer Bank ke rekening masing-masing petugas survei.
  • ☑ Bukti Potong e-Bupot 21/26 (Kode 21-100-02) dari Coretax DJP.
